# City of Toronto Open Data (ckan0-cf-opendata-inter-prod-toronto-ca)

City of Toronto Open Data is a municipal government open-data portal for Canada running **CKAN**, exposing a standardized catalog API over ~543 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/ckan0-cf-opendata-inter-prod-toronto-ca/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=ckan0-cf-opendata-inter-prod-toronto-ca-api-evangelist&utm_content=repo)
